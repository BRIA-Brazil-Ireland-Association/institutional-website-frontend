# Institutional Website Frontend

Boilerplate Next.js com Tailwind CSS e React Query.

## Configuração

1. Instale dependências:
    ```bash
    npm install
    ```
2. Inicie o ambiente de desenvolvimento:
    ```bash
    npm run dev
    ```

## Estrutura incluída

- `app/` com App Router do Next.js
- `tailwind.config.ts` e `postcss.config.js`
- `@tanstack/react-query` com provider e exemplo de uso
- `.env` inicial para variáveis de ambiente públicas

## Variáveis de ambiente

- `NEXT_PUBLIC_SITE_NAME`
- `NEXT_PUBLIC_API_BASE_URL`
- `NEXT_PUBLIC_ANALYTICS_ID`
